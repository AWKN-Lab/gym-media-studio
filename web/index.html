素材

本地化直连：登记本机文件夹后平台只建索引，不上传、不复制、原文件保持原位，剪辑时直接读原片。文件名带关键词（教练、器械、深蹲、门店、团课、有氧）会优先匹配对应分镜。

本机素材文件夹 纯本地

控制台跑在哪台电脑，就选那台电脑上的目录。点「浏览本机目录」可逐级点选， 也可以直接粘贴完整路径（如 D:\门店实拍）。平台只用 ffprobe 读时长与分辨率， 不会把视频传到任何服务器，也不会拷进项目；移除登记只删索引，绝不删除原文件。 支持 mp4 / mov / mkv / avi / m4v / webm / jpg / png，最多递归 3 层、400 个文件。 列表里的小图是按需生成的 360×640 缩略图缓存（data/thumbs/），不是原片副本。
