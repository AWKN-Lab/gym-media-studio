三、四条硬契约（都有门禁钉住）

1 程序只读 + 数据可写

core/paths.py 用单一环境变量 LYNVOS_HOME 覆盖 core/util.py 的 ROOT，六个路径常量（config/data/output/assets/web）整体重定向。不设变量时逐字保持开发期行为，既有 78 项任务与所有 A/B 严格回退不受影响。

顺手修了 core/playbook.py 自己另算一份 ROOT 的问题，否则安装后用户改的方法库/承诺方案库读不到。

2 白名单引导

首次启动只播种 config.json、web/index.html、assets 程序资源、data/baseline/*.json、assets/gym/*。用户数据仅在缺失时补，程序资源按哈希覆盖（升级不冲掉用户改过的方案）。

864 MB 的 data/browser-*、_cdp_probe、_pipe_probe、runs 一律不进包、不复制。

3 关窗不留后台服务

父子双保险：Tauri 在 RunEvent::Exit 与「启动失败/超时」两条路径都 kill + wait 子进程；sidecar 另有 --parent-pid 守护线程，父进程被强杀也会清理 port.json 并 os._exit(0)。

这条正是本轮「后台任务是否有问题」的直接回应。

4 多开不冲突

启动先读 port.json 并实测端口是否存活；已有实例则只开新窗口、不重复拉起内核、也不误杀别人的内核。端口占用时 sidecar 自动顺延并回写端点文件。

四、怎么构建（通道恢复后一步到位）

双击  desktop/build.bat
或命令行：
  python desktop/build.py                 # 精简完整包（推荐，约 80–150 MB）
  python desktop/build.py --with-whisper # 全量离线包（含 faster-whisper 模型链）
  python desktop/build.py --console      # 留控制台窗口排障
  python desktop/build.py --skip-tauri   # 只重打内核
  python tests/falsify_desktop_paths.py  # 四组严格证伪

产物：
  desktop/dist/凌扬运动工作台_1.0.0_x64-setup.exe
  desktop/dist/sidecar/lynvos-sidecar.exe
  desktop/dist/BUILD_REPORT.json

构建脚本会做环境自检、Pillow 生成品牌图标、自动补装 PyInstaller 6.20、npm install、NSIS 打包，并跑「禁止缓存混入」清单门禁；任何一步失败写进 BUILD_REPORT.json 而不是静默通过。
